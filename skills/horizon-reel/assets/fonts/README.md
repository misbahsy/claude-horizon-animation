Fonts bundled so every render is identical on every machine. All three are under the SIL Open Font License 1.1; the licence text for each is beside it.

- `source-serif-4-variable.woff2`: Source Serif 4 (Adobe). The default arc and card serif. `OFL-source-serif-4.txt`.
- `newsreader-variable.woff2`: Newsreader (Production Type). The alternative serif, a little more bookish. `OFL-newsreader.txt`.
- `geist-variable.woff2`: Geist (Vercel). The default lockup wordmark face. `OFL-geist.txt`.

Latin subsets from Google Fonts. To add a face, drop the woff2 and its licence here and register it in `assets/reel.html`.
